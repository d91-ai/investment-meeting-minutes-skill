# 专家交流正文语义

本文件只说明专家交流的类型语义。问题的精确格式统一引用 `../output_contract.md`，不得在本文件另行定义变体。

## 1. 适用范围

适用于行业专家访谈、产业链专家交流、渠道调研和主题电话会。专家个人判断不得改写成公司官方口径或已确认事实。

## 2. 正文组织

- 按源材料的真实问答顺序整理，不按主题重新汇总；
- 问题使用共享输出契约规定的不加粗问题格式；
- 问题后下一段直接写回答，不增加提问、回答或专家回答等整理标签；
- 保留专家第一人称、估计、假设、条件、时间范围和不确定性；
- 明确区分专家观察、转述信息和可核验事实；
- 只进行必要的正常编辑，不把回答改写成确定性结论；
- AI 判断、外部背景和核验说明不得进入发言整理正文。

## 3. 语言清理与否定保真

- 删除独立寒暄、致谢和没有信息作用的口头填充；寒暄与实质问题在同一句时，只删除寒暄并保留完整问题；
- 合并确定无语义作用的机械重复，例如“然后然后”整理为“然后”；
- 不得机械删除连续否定词。“不不”“没有没有”必须结合上下文判断是口吃重复、强调还是否定纠正；
- 完整保留“不是 A，而是 B”等自我纠正，以及“可能、未必、暂时、倾向于”等观点强度；
- 清理后仍须保留条件、时间、数字、因果链和问题回答关系。

简单示例：

| 源材料 | 可接受整理 |
|---|---|
| 好的，谢谢。然后还有一个问题，今年是否会扩产？ | 【今年是否会扩产？】 |
| 然后然后看明年的需求情况。 | 然后看明年的需求情况。 |
| 不不，我不是说需求下滑，而是增速可能放缓。 | 不，我不是说需求下滑，而是增速可能放缓。 |
| 没有没有，需求并没有下滑，暂时只是交付推迟。 | 没有，需求并没有下滑，暂时只是交付推迟。 |

## 4. 复核重点

- 问题与回答是否正确配对；
- 专家判断是否被错误升级为事实；
- 估计值、范围、条件和不确定性是否保留；
- 寒暄、机械重复和断句是否清理，否定、自我纠正和观点强度是否保持；
- 所有问题是否完全符合共享问题格式。
