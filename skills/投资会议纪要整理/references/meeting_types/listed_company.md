# 公司交流正文语义

本文件只说明公司交流的类型语义；双层结构、元信息、标题和粗体格式统一引用 `../output_contract.md`。

## 1. 元信息

文首使用共享元信息，并额外增加普通字体项目符号 `- 会议标的：公司名(代码)`。公司名称与代码必须核验；不得把板块、行业或“待确认”占位写入该字段。

## 2. 会议纪要层

- 按管理层问答和说明的实际逻辑归纳，可压缩相邻问答；
- 使用 `### 提问者`、`### 公司/管理层` 和 `**【……】**` 概括标题；
- 可以使用“管理层表示”等纪要语言，但不得把管理层估计、规划、指引或转述升级为事实；
- 完整保留数字口径、同比环比、时间范围、条件、风险和不确定性。

## 3. 原文校对层

- 保留真实问答顺序、发言人、第一人称及问题回答关系；
- 仅清理明显转写错误、无信息填充和错误断句；
- 概括标题可以辅助阅读，但不得替代问题或改变公司口径。

## 4. 复核重点

- 纪要层每项经营结论是否可回溯至原文校对层；
- 管理层口径、整理者归纳和外部核验是否严格分离；
- 数字、单位、期间、条件及不确定性是否完整；
- 未确认项是否仅以内嵌粗体及内部审核材料保留。
